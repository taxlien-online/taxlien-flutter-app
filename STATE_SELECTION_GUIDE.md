# Руководство по выбору штатов для .rada файлов

## 🎯 Обзор

TaxLien.online теперь позволяет пользователям выбирать, данные каких штатов загружать, что экономит память и ускоряет работу приложения.

## 📁 Доступные .rada файлы

```
/assets/
├── taxlien_data.rada       - Все штаты (полный набор)
├── taxlien_florida.rada    - Только Florida
├── taxlien_arizona.rada    - Только Arizona
├── taxlien_demo.rada       - Демо данные
└── taxlien.rada            - По умолчанию
```

## 🎨 Где пользователь может выбрать штаты

### 📱 В интерфейсе приложения:

**Навигация:** `Профиль → Выбор штатов`

```
Главный экран
  ↓
Вкладка "Профиль"
  ↓
"Выбор штатов" (иконка карты 🗺️)
  ↓
Экран выбора с чекбоксами
  ↓
Выбрать нужные штаты
  ↓
Нажать "ПРИМЕНИТЬ"
  ↓
Данные загружаются
```

### 🚀 При первом запуске (опционально):

Можно добавить в onboarding flow - пользователь выбирает штаты сразу при первом запуске.

## 🎛️ Варианты выбора

### 1. Один штат
Например, только Florida:
- ✅ Минимальный размер данных
- ✅ Быстрая загрузка
- ✅ Меньше трафика
- ⚠️ Ограничено одним штатом

### 2. Несколько штатов
Например, Florida + Arizona:
- ✅ Данные по нескольким штатам
- ✅ Всё равно меньше чем ALL
- ✅ Гибкость
- ⚠️ Немного больше размер

### 3. All States
Полный набор данных:
- ✅ Все данные доступны
- ✅ Не нужно менять позже
- ⚠️ Больший размер файла
- ⚠️ Дольше загрузка

## 🔧 API для разработчиков

### Программный выбор штатов:

```dart
// Выбрать только Florida
await PreloadService.setSelectedStates({'FL'});

// Выбрать Florida + Arizona
await PreloadService.setSelectedStates({'FL', 'AZ'});

// Выбрать все штаты
await PreloadService.setSelectedStates({'ALL'});

// Получить текущий выбор
final states = PreloadService.getSelectedStates();
print('Selected: ${states.join(", ")}');

// Получить размер для штата
final size = await PreloadService.getStateDataSize('FL');
print('Products: ${size['products']}');
print('Size: ${size['file_size_kb']}KB');
```

### Проверка текущего состояния:

```dart
// Проверить какие штаты выбраны
final selectedStates = PreloadService.getSelectedStates();

// Проверить используется ли несколько штатов
if (PreloadService.isUsingMultipleStates) {
  print('Using multiple state files');
}

// Получить информацию об источнике данных
final info = await PreloadService.getDataSourceInfo();
print('Selected states: ${info['selected_states']}');
print('Is multiple: ${info['is_multiple_states']}');
```

## 💾 Сохранение выбора

Выбор штатов **автоматически сохраняется** в SharedPreferences и используется при следующих запусках приложения.

**Ключ:** `selected_rada_states`

## 🔄 Логика работы

### При первом запуске:
1. Проверяется есть ли сохраненный выбор
2. Если нет - загружается 'ALL' по умолчанию
3. Пользователь может изменить в любой момент

### При изменении выбора:
1. Очищается кеш
2. Загружаются выбранные .rada файлы
3. Данные объединяются (для множественного выбора)
4. Кешируются для offline использования
5. Выбор сохраняется

### Логика выбора "ALL":
- Если выбран "ALL" - остальные чекбоксы снимаются
- Если выбран конкретный штат - "ALL" снимается
- Если сняты все чекбоксы - автоматически выбирается "ALL"

## 🎓 Best Practices

### Рекомендации:

1. **Для активных пользователей одного штата:**
   - Выбрать конкретный штат (FL или AZ)
   - Экономия до 80% памяти

2. **Для инвесторов в нескольких штатах:**
   - Выбрать 2-3 нужных штата
   - Экономия до 50% памяти

3. **Для исследователей/профессионалов:**
   - Выбрать "All States"
   - Полный доступ ко всем данным
