# Tax Lien NFT Prototype

Этот прототип демонстрирует функциональность превращения купленных закладных в NFT (Non-Fungible Tokens) в мобильном приложении TaxLien.

## Основные возможности

### 1. Создание NFT из закладных
- Превращение купленных закладных в уникальные NFT
- Кастомизация имени и описания NFT
- Автоматическое определение редкости на основе стоимости недвижимости
- Расчет уровня риска на основе срока погашения

### 2. Управление NFT коллекцией
- Просмотр всех созданных NFT
- Детальная информация о каждом NFT
- История транзакций
- Статус NFT (создан, передан, сожжен)

### 3. Торговля NFT
- Передача NFT другим пользователям
- Сжигание NFT (уничтожение)
- Просмотр NFT в маркетплейсе

### 4. Система редкости
- **Common** (обычный): < $50,000
- **Rare** (редкий): $50,000 - $100,000
- **Epic** (эпический): $100,000 - $200,000
- **Legendary** (легендарный): > $200,000

### 5. Уровни риска
- **Low** (низкий): > 90 дней до погашения
- **Medium** (средний): 30-90 дней до погашения
- **High** (высокий): < 30 дней до погашения

## Структура данных

### NFT Metadata
```dart
class NFTMetadata {
  final String name;           // Название NFT
  final String description;    // Описание
  final String image;          // URL изображения
  final Map<String, dynamic> attributes;  // Атрибуты (редкость, риск и т.д.)
  final Map<String, dynamic> properties;  // Свойства закладной
}
```

### TaxLienNFT
```dart
class TaxLienNFT {
  final String id;                    // Уникальный ID NFT
  final String tokenId;               // Token ID в блокчейне
  final TaxLien originalLien;         // Исходная закладная
  final NFTMetadata metadata;         // Метаданные NFT
  final String ownerAddress;          // Адрес владельца
  final DateTime createdAt;           // Дата создания
  final String status;                // Статус (minted, transferred, burned)
  final double? currentValue;         // Текущая стоимость
  final List<String> transactionHistory; // История транзакций
}
```

## Экраны приложения

### 1. NFT Dashboard
- **My NFTs**: Просмотр собственных NFT
- **Marketplace**: Просмотр NFT других пользователей
- **Mint NFT**: Создание новых NFT из закладных

### 2. NFT Card
- Визуальное отображение NFT с градиентом по редкости
- Информация о стоимости и уровне риска
- Кнопки действий (передача, сжигание)

### 3. NFT Detail Dialog
- Полная информация о NFT
- Детали закладной
- История транзакций
- Финансовая информация

### 4. Mint NFT Dialog
- Предварительный просмотр закладной
- Кастомизация NFT
- Предварительный просмотр результата
- Информация о преимуществах

## Техническая реализация

### Сервисы
- `NFTService`: Управление NFT (создание, передача, сжигание)
- `TaxLienService`: Управление закладными (обновлен с моковыми данными)

### Виджеты
- `NFTCard`: Карточка NFT для отображения в сетке
- `NFTDetailDialog`: Диалог детального просмотра
- `MintNFTDialog`: Диалог создания NFT

### Навигация
- Добавлен новый таб "NFTs" в главную навигацию
- Интеграция с существующей архитектурой приложения

## Преимущества NFT конвертации

1. **🎯 Торгуемость**: NFT можно продавать на специализированных маркетплейсах
2. **🔒 Неизменность**: Запись о владении хранится в блокчейне
3. **💎 Уникальность**: Каждый NFT уникален и представляет конкретную закладную
4. **📈 Потенциал роста**: Возможность увеличения стоимости
5. **🌐 Глобальная доступность**: Доступ к инвестициям из любой точки мира
