Приложение автоматически определяет язык системы устройства и использует его для интерфейса.

**Логика работы:**
1. При запуске приложение проверяет язык системы

3. Если язык не поддерживается → используется английский

  Locale('hi', ''), // Hindi

**Настроен callback выбора локали:**
```dart
localeResolutionCallback: (locale, supportedLocales) {
  for (var supportedLocale in supportedLocales) {
    if (supportedLocale.languageCode == locale?.languageCode) {
      return supportedLocale;
    }
  }
  return supportedLocales.first; // English по умолчанию
},
```

## Особенности

### RTL (Right-to-Left) поддержка
Для иврита Flutter автоматически изменяет направление текста справа налево. Никаких дополнительных настроек не требуется.

### Непереведенные строки
Если какая-то строка не переведена в .arb файле, она автоматически отобразится на английском языке.

### Добавление новых переводов
1. Откройте соответствующий `.arb` файл
2. Найдите ключ и измените значение
3. Выполните `flutter gen-l10n`
4. Перезапустите приложение
