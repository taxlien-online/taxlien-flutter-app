### Design Philosophy
- **Mobile-First:** Design for iOS/Android (Flutter)
- **Conversion-Focused:** Every screen should move user toward premium
- **Gamification:** Progress bars, badges, achievements
- **Educational:** Learn-to-Earn = education unlocks features
- **Social Proof:** Show user counts, testimonials, success stories

### UI/UX Principles
1. **Clarity over Complexity** - simple, intuitive flows
2. **Visual Hierarchy** - guide eye to important elements
3. **Consistent Patterns** - reusable components
4. **Microinteractions** - animations, feedback, delight
5. **Accessibility** - readable fonts, contrast, tap targets

### Design System
- **Colors:**
  - Primary: Blue/Indigo (trust, stability)
  - Accent: Green (money, growth)
  - Warning: Orange (urgency)
  - Error: Red (alerts)
  - Background: White/Light gray
- **Typography:**
  - Headings: Bold, 24-32px
  - Body: Regular, 16px
  - Small: 12-14px
- **Spacing:**
  - Grid: 8px base unit
  - Padding: 16px (2 units), 24px (3 units)
  - Margins: 8px, 16px, 24px
