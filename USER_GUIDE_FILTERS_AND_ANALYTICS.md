## 🎯 Как смотреть участки без закладных и с закладными

### 1. В Marketplace (Маркетплейс)

**Навигация:** `Главный экран → Вкладка "Маркетплейс"`

#### Доступные фильтры:

```
Маркетплейс
├── 🔍 Поиск (вверху)
├── 🎛️ Расширенный поиск (кнопка поиска)
└── Список продуктов
```

#### A) Участки БЕЗ активных закладных:

**Способ 1: Через расширенный поиск**
```
1. Маркетплейс → 🔍 (иконка поиска справа вверху)
2. Откроется "Advanced Search"
3. Нажмите "Configure" (настроить фильтры)
4. Выберите фильтры:
   - Status: "Available" (доступно)
   - Property Type: выберите тип
   - Lien Status: "No Active Liens" (нет активных закладных)
5. Нажмите "Apply"
```

**Способ 2: В основном маркетплейсе**
```
Маркетплейс → Фильтр → Статус:
- Выбрать "Available" (без закладных)
- Можно комбинировать с другими фильтрами
```

#### B) Участки С активными закладными:

**В расширенном поиске:**
```
1. Маркетплейс → 🔍 Advanced Search
2. Configure filters
3. Lien Status: "Active Liens" (активные закладные)
4. Apply
```
