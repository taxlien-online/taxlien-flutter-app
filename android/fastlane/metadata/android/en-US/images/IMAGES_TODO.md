# Необходимо добавить изображения

## ✅ Готово:
- [x] icon/icon.png (512x512px) - иконка приложения

## ❌ Требуется добавить:

### 1. Feature Graphic (ОБЯЗАТЕЛЬНО)
**Путь:** `featureGraphic/featureGraphic.png`
**Размер:** 1024x500 пикселей
**Формат:** JPEG или PNG (без альфа-канала)
**Описание:** Главное промо-изображение, которое показывается в Google Play Store

### 2. Скриншоты телефона (ОБЯЗАТЕЛЬНО - минимум 2)
**Путь:** `phoneScreenshots/`
**Файлы:** 
- `1_screenshot.png`
- `2_screenshot.png`
- `3_screenshot.png` (опционально)
- ... до 8 файлов максимум

**Требования:**
- Формат: JPEG или PNG
- Соотношение сторон: 16:9 или 9:16
- Минимальная сторона: 320px
- Максимальная сторона: 3840px

**Рекомендации по контенту скриншотов:**
1. Главный экран с картой и списком свойств
2. Экран с детальной информацией о свойстве
3. Экран поиска и фильтров
4. Экран избранного/watchlist
5. Экран с аналитикой

### 3. Скриншоты планшета (ОПЦИОНАЛЬНО)
**Путь:** `tenInchScreenshots/`
**Описание:** То же самое, что и для телефонов, но оптимизированные для планшетов

## Как добавить изображения:

1. Создайте скриншоты вашего приложения
2. Отредактируйте их до нужных размеров
3. Скопируйте в соответствующие папки
4. Убедитесь, что имена файлов правильные

## Пример команд:

```bash
# Скопировать feature graphic
cp ~/путь/к/изображению.png featureGraphic/featureGraphic.png

# Скопировать скриншоты
cp ~/путь/к/screenshot1.png phoneScreenshots/1_screenshot.png
cp ~/путь/к/screenshot2.png phoneScreenshots/2_screenshot.png
```

## После добавления всех изображений:

Запустите загрузку метаданных:
```bash
fastlane android metadata
```

Или полный релиз:
```bash
fastlane android release
```
